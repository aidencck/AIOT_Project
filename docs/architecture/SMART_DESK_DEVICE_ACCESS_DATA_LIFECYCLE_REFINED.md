# 智能升降桌设备接入系统全域数据全生命周期管理方案（梳理版）

## 1. 目标与边界

| 项 | 定义 |
|---|---|
| 目标 | 建立智能升降桌从设计、制造、接入、运行、运维、退网到报废的全域数据管理体系 |
| 核心要求 | 可接入、可追溯、可分层、可治理、可归档、可删除 |
| 适用范围 | 设备接入、设备控制、数字孪生、遥测时序、事件告警、OTA、售后、AI 诊断、审计合规 |
| 不含范围 | ERP、财务、供应链结算、非设备直接相关经营系统 |
| 终局形态 | 主数据单一真源，状态数据分层承载，控制数据闭环可追溯，合规数据可审计可删除 |

## 2. 生命周期分段

| 阶段 | 阶段定义 | 核心数据 |
|---|---|---|
| `L0 设计建模` | 设备与平台规则建模 | 产品型号、物模型、协议、命令字典、事件字典、告警字典、固件矩阵 |
| `L1 制造入库` | 设备出厂与产测建档 | SN、设备身份、控制板编号、模组编号、校准参数、产测记录、批次信息 |
| `L2 首次接入` | 设备首连、认证、激活、绑定 | 证书/密钥、接入日志、会话、激活记录、用户/空间绑定 |
| `L3 运行期` | 日常运行与控制闭环 | 遥测、影子、命令、回执、事件、告警、使用行为、健康评分 |
| `L4 运维期` | 升级、诊断、售后 | OTA 包、灰度任务、升级结果、工单、维修、换件、AI 诊断、反馈 |
| `L5 退网期` | 解绑与停服 | 冻结状态、解绑记录、凭证吊销、配置封存 |
| `L6 报废期` | 资产注销与数据处理 | 隐私删除、审计归档、资产注销、质量证据保留 |

## 3. 全域数据分层

| 分层 | 作用 | 典型数据 | 建议存储 |
|---|---|---|---|
| `边缘层` | 断网自治与本地保护 | 最近配置、预设位、防撞阈值、校准参数 | 设备本地 Flash/SQLite |
| `热数据层` | 实时控制与会话态 | 在线状态、影子当前态、命令回执、会话态 | Redis |
| `事务层` | 主数据与业务闭环 | 设备、绑定、OTA、工单、诊断、反馈、案例 | MySQL |
| `时序层` | 高频信号与运行轨迹 | 高度、电流、温度、运动状态、心跳 | TSDB/时序表 |
| `对象归档层` | 长文本与大对象留存 | 固件包、报告、维修记录、诊断上下文 | Object Storage |
| `分析层` | 指标、画像、治理快照 | DWD、DWS、ADS、门禁快照、训练导出 | 数仓/分析库 |

## 4. 数据域拆解

| 数据域 | 核心对象 | 主责系统 | 生命周期重点 |
|---|---|---|---|
| 主数据域 | 产品、设备、部件、固件、租户、空间、用户 | 设备平台/账户平台 | 统一编码、单一真源、版本冻结 |
| 身份域 | 证书、密钥、clientId、authIdentity | 接入平台 | 强安全、可吊销、可轮换 |
| 连接域 | 会话、在线状态、心跳、重连、IP、协议 | 接入平台 | 短期热存、聚合后归档 |
| 控制域 | 升降命令、预设位、儿童锁、防撞阈值 | 控制服务 | 命令回执成对建模 |
| 遥测域 | 高度、电流、温度、电源、方向、负载估计 | 数据平台 | 高频采样、冷热分层 |
| 孪生域 | `desired/reported/delta/version` | 设备平台 | 当前态强可用、关键版本留痕 |
| 事件域 | 上下线、控制完成、防撞、卡顿、校准、过流 | 事件平台 | 事件标准化、全链路 trace |
| 告警域 | 安全告警、持续告警、恢复、抑制状态 | 运维平台 | 分级保留、严重事件长期审计 |
| AI/规则域 | 场景、诊断、反馈、案例、规则草案 | AI/规则平台 | 可回溯、可训练、可门禁 |
| 运维域 | OTA、灰度、维修、换件、工单 | 运维/售后平台 | 与设备、批次、版本强关联 |
| 审计合规域 | 操作日志、授权日志、导出、删除审计 | 安全合规平台 | 独立权限、独立留存 |

## 5. 智能升降桌专属对象

| 类别 | 关键字段 |
|---|---|
| 设备身份 | `deviceId`、`sn`、`productKey`、`controllerBoardId`、`motorPairId`、`bluetoothMac/wifiMac` |
| 结构能力 | 双/单电机、最大/最小高度、最大行程、升降速度、承重等级、防撞等级 |
| 校准参数 | 零点高度、最大行程校准值、左右电机同步偏差、出厂校准时间 |
| 使用状态 | 当前高度、站立时长、久坐时长、日升降次数、站坐切换次数 |
| 健康状态 | 过流次数、防撞次数、异常停机次数、控制成功率、平均升降耗时 |
| 服务状态 | 保修状态、最近维修时间、换件次数、固件版本分布、批次风险标签 |

## 6. 主键与关联键

### 6.1 一级统一键

- `tenantId`
- `deviceId`
- `globalDeviceId`
- `sn`
- `traceId`
- `eventId`
- `commandId`
- `sessionId`
- `alarmId`
- `otaTaskId`
- `workOrderId`

### 6.2 二级业务键

- `spaceId`
- `userId`
- `deskId`
- `firmwareVersion`
- `productKey`
- `sceneType`
- `occurredAt`

### 6.3 强约束

- 所有事件必须具备 `deviceId + occurredAt + traceId/eventId`
- 所有控制链数据必须具备 `commandId`
- 所有 AI 闭环数据必须能回溯到 `eventId` 或 `commandId`

## 7. 采集与入库规则

| 规则 | 要求 |
|---|---|
| 事件先行 | 所有接入事实先进入标准事件总线，再分发到状态、孪生、分析链路 |
| 命令闭环 | 每条命令必须关联 `accepted/started/completed/failed/timeout` |
| 分级采样 | 高度、电流在运动期秒级采样，静止期分钟级采样，异常期自动升采样 |
| 异常全量 | 防撞、过流、卡顿、倾斜、校准丢失必须全量留痕 |
| 状态事件解耦 | 在线状态、当前高度是状态；控制完成、防撞触发是事件 |

## 8. 数据标准与分级

### 8.1 标准

- `设备状态`：`online/offline/fault/upgrading/frozen/retired`
- `运动状态`：`idle/up/down/paused/blocked/calibrating`
- `命令状态`：`accepted/dispatched/executing/completed/failed/timeout/cancelled`
- `告警等级`：`P1/P2/P3/P4`
- `单位约束`：
  - 高度统一 `mm`
  - 电流统一 `mA`
  - 时间统一 `UTC+0`
  - 固件版本统一语义化版本

### 8.2 数据分级

| 级别 | 数据类型 | 原则 |
|---|---|---|
| `S1` | 命令、回执、告警、OTA 状态 | 强审计，优先保留 |
| `S2` | 高度、电流、温度、在线状态 | 按热温冷分层保留 |
| `S3` | 站立时长、提醒响应、使用习惯 | 默认最小化采集，可匿名化 |
| `S4` | 密钥、证书、手机号、位置 | 加密、脱敏、最小权限 |

### 8.3 删除原则

- 用户可识别行为数据优先匿名化
- 密钥类数据退网即销毁
- 审计类数据只归档不篡改
- 重大安全与质量事件不做普通过期删除

## 9. 生命周期管理矩阵

| 数据域 | 关键数据 | 主存 | 热度层 | 保留策略 | 归档/删除策略 |
|---|---|---|---|---|---|
| 产品主数据 | 型号、物模型、能力矩阵 | MySQL | 温 | 长期 | 仅版本冻结 |
| 设备身份 | SN、证书、密钥、模组号 | MySQL + 密钥库 | 温 | 生命周期+审计期 | 退网吊销、销毁密钥 |
| 产测校准 | 校准值、测试结果 | MySQL/对象存储 | 温冷 | 长期 | 冷归档 |
| 接入会话 | 登录、心跳、断连、IP | Redis + 明细库 | 热 | 7-30 天 | 聚合后冷存 |
| 遥测时序 | 高度、电流、移动状态 | TSDB/时序表 | 热温冷 | 明细 7-30 天，聚合 180-365 天 | 明细过期、保留聚合 |
| 设备影子 | `desired/reported/delta` | Redis + 快照表 | 热 | 当前态长期 | 历史短期、关键版本保留 |
| 控制命令 | 升降、预设、锁定、提醒 | 事务库 | 温 | 180-365 天 | 超期归档 |
| 事件告警 | 防撞、过流、卡顿、离线 | 事件库 | 热温 | P1/P2 2-3 年，普通 180-365 天 | 严重事件长期留痕 |
| AI诊断 | 场景、根因、建议 | MySQL/对象存储 | 温 | 1-3 年 | 上下文脱敏后保留 |
| 用户行为 | 站坐习惯、提醒响应 | 明细库/画像库 | 温冷 | 默认最短化 | 超期匿名化 |
| OTA数据 | 固件包、灰度、升级结果 | MySQL + 对象存储 | 温 | 1-3 年 | 历史包封存 |
| 维修售后 | 工单、换件、结论 | MySQL | 温冷 | 保修期+审计期 | 冷归档 |
| 审计合规 | 操作日志、删除日志 | 审计库 | 温冷 | 2-5 年 | 只归档不改写 |

## 10. 治理与合规

### 10.1 质量治理

- `完整性`：接入成功率、事件丢失率、回执缺失率、影子漂移率
- `一致性`：当前高度与影子 `reported` 一致；命令完成态与最终高度一致；OTA 状态与固件版本一致
- `准确性`：高度跳变校验、电流异常窗口校验、防撞误触发率校验
- `及时性`：在线状态延迟、回执延迟、告警生成延迟、升级结果回传延迟
- `唯一性`：`eventId/commandId/alarmId/otaTaskId` 去重
- `可追溯性`：任一售后结论可回溯到设备批次、固件版本、异常事件、用户反馈

### 10.2 安全合规

- 设备证书/密钥统一托管在密钥系统
- 设备侧到接入层使用 TLS
- 内部接口使用服务身份或内部令牌
- `sn/mac/手机号/位置/行为标签` 按字段加密或脱敏
- 运维、售后、分析、AI 训练使用不同数据视图
- 办公行为数据默认不做跨租户分析
- 用户解绑、设备退网、租户注销必须生成删除审计

## 11. 智能升降桌专用规则

- 校准参数属于关键安全数据，不允许普通 App 直接覆盖
- 防撞事件必须全量留痕，并记录动作来源、交互来源、发生时高度、电流、速度
- 双电机偏差、同步失败、重复校准次数需要单独建模
- 久坐提醒与站坐行为数据和设备健康数据分库存放
- 家庭场景使用 `homeId/roomId`；办公场景使用 `tenantId/siteId/floorId/spaceId`
- 儿童锁/安全锁配置变更必须进入审计域

## 12. 控制面拆分

| 控制面 | 核心职责 |
|---|---|
| 设备接入控制面 | 注册、证书签发、冻结/解冻、黑名单、协议配置 |
| 设备运行控制面 | 影子管理、命令编排、异常阈值、提醒策略、预设位策略 |
| 设备治理控制面 | 数据质量监控、影子漂移监控、命令超时补偿、时序质量门禁 |
| AI 控制面 | 诊断场景管理、案例沉淀、反馈闭环、模型门禁、训练导出 |
| 合规控制面 | 租户隔离、数据导出、删除审批、脱敏策略、保留周期配置 |

### 13.1 接入域

### 13.2 控制域

- 命令成功率
- 平均升降完成时长
- 命令超时率

### 13.3 健康域

- 防撞触发率
- 电机过流率
- 校准失效率
- 异常停机率

### 13.4 体验域

- 日均站坐切换次数
- 久坐提醒响应率
- 平均站立时长

### 13.5 运维域

- OTA 成功率
- 售后返修率
- 批次故障聚集度

### 13.6 AI 治理域

- fallback 占比
- 一次解决率
- 案例沉淀率

## 15. 实施优先级

| 优先级 | 建设项 |
|---|---|
| `P0` | 统一主键体系、统一命令/回执模型、统一高度/电流/时间标准、建设接入事件总线 |
| `P1` | 建影子模型、建时序落库、建异常事件与告警模型、建 OTA 与售后闭环 |
| `P2` | 建 AI 诊断与反馈闭环、建行为画像匿名化体系、建租户级数据治理与删除控制面 |
| `P3` | 建跨批次质量预测、配件级寿命预测、空间级健康分析 |

## 16. 终局形态

- `主数据`：只保留一份主真源
- `状态数据`：由影子和时序协同承接
- `控制数据`：以命令/回执对为核心真源
- `异常数据`：以事件和告警双模承接
- `AI 数据`：从事实层直接构造，不绕业务接口临时拼装
- `合规数据`：独立审计、独立权限、独立删除闭环
- `全域数据`：实现“可接入、可追溯、可分层、可治理、可归档、可删除”
