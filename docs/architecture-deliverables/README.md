# AIOT 架构交付包（执行版）

本目录是“架构方案可执行交付包”，用于把分散文档收敛为单一评审入口（SSOT）。

## 使用顺序

1. `A01_架构总纲.md`
2. `A02_AsIs图册.md`
3. `A03_ToBe蓝图.md`
4. `A04_演进路线与里程碑.md`
5. `A05_ADR决策集.md`
6. `A06_质量预算与SLO.md`
7. `A07_治理门禁清单.md`
8. `A08_验收报告模板.md`

## 评审机制

- 评审节奏：每周一次架构评审会 + 每 Sprint 一次里程碑复盘。
- 变更要求：架构变更必须至少同步更新 `A03/A05/A07` 三份文档。
- 生效条件：通过 `A07` 门禁并在 `A08` 完成验收留档后生效。

## 角色责任

- 架构 Owner：维护 `A01~A07` 的准确性和一致性。
- 业务 Owner：确认 `A01/A04/A08` 的业务目标与验收口径。
- 工程 Owner：落地 `A06/A07` 的指标、告警、发布与回滚机制。
