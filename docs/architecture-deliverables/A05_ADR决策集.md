# A05 ADR 决策集

## 使用说明

- ADR 目标：记录关键架构决策、备选方案、取舍理由与回滚触发条件。
- 适用范围：跨服务边界、通信机制、数据模型、部署形态、安全策略。
- 最低要求：每个 ADR 必须包含“业务影响”和“可验证指标”。

## ADR 模板

### ADR-`<编号>`：`<标题>`

- 状态：`proposed | accepted | deprecated`
- 日期：`<YYYY-MM-DD>`
- 决策人：`<待填写>`
- 背景：`<问题描述>`
- 备选方案：`<A/B/C>`
- 决策结论：`<选择结果>`
- 取舍理由：`<收益/成本/风险>`
- 业务影响：`<对收入/成本/交付效率的影响>`
- 验证指标：`<SLO/性能/故障率>`
- 回滚触发：`<触发条件>`
- 回滚方案：`<执行步骤>`

## 初始 ADR 建议清单

- ADR-001：事件中枢继续使用 `Redis Stream` 的边界与迁移触发条件。
- ADR-002：`Nacos Discovery` 到 `Nacos Config` 的接入策略与治理标准。
- ADR-003：内部调用身份治理（`X-Internal-Token` 生命周期与轮换策略）。
- ADR-004：Compose 到 K8s 迁移的分阶段准入标准。
